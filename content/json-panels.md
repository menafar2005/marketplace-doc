## JSON panel چیست؟ {#what}

JSON panel به کاربر اجازه می‌دهد داده‌ی اپ تو را داخل دیدار ببیند و از آن استفاده کند؛ یک نمایش بصری از داده‌ای که در اپ تو وجود دارد. ظاهر پنل را دیدار با اجزای آماده‌ی خودش می‌سازد؛ تو ساختار داده‌ی پنل را در یک فایل JSON تعریف می‌کنی.

چند مثال: مانده‌حساب و فاکتورهای باز مشتری کنار پرونده‌ی شخص، وضعیت سفارش‌ها کنار معامله، یا آخرین تیکت‌های پشتیبانی کنار پرونده‌ی شرکت.

## در UI دیدار کجاست؟ {#visibility}

- در **سایدبار سمت چپ** صفحه‌های **Deal details**، **Person details** و **Organization details**.
- کاربر برای دیدن پنل کاری انجام نمی‌دهد؛ با باز کردن صفحه‌ی جزئیات، پنل را می‌بیند.
- هر اپ در هر صفحه‌ی جزئیات فقط **یک پنل** دارد: یا JSON panel یا [Custom panel](/custom-panels)، نه هر دو. پس هر اپ حداکثر سه پنل دارد.

## JSON panel را چطور اضافه کنم؟ {#add}

در Developer Hub، تب **App extensions**، کارت **JSON panel** را انتخاب کن و **Add** بزن.

| فیلد | توضیح |
| --- | --- |
| Panel name **(الزامی)** | حداکثر ۳۰ کاراکتر. |
| Panel description | اختیاری؛ حداکثر ۱۵۰ کاراکتر. |
| API endpoint **(الزامی)** | endpoint اپ تو؛ URL معتبر و HTTPS. |
| JWT secret **(الزامی)** | [توضیح](/custom-ui-extensions#jwt-secret) |
| JSON data structure **(الزامی)** | فایل `.json` معتبر که ساختار پنل را تعریف می‌کند. |
| Panel locations **(الزامی)** | حداقل یکی از Deal details، Person details، Organization details. در صفحه‌ای که اپ Custom panel دارد، JSON panel اضافه نمی‌شود. |

## هنوز مستند نشده {#open}

> [!WARNING]
> قرارداد فنی JSON panel هنوز در منبع فنی نیامده و در این داک حدس زده نمی‌شود: قالب «JSON data structure»، اینکه دیدار کی و با چه پارامترهایی API endpoint را برای گرفتن داده‌ی پنل صدا می‌زند، و قالب پاسخی که endpoint باید برگرداند. تا وقتی این قرارداد منتشر نشده، برای نمایش داده‌ی سفارشی در صفحه‌ی جزئیات از [Custom panel](/custom-panels) استفاده کن.
